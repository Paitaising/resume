# 张笑源 - 个人介绍网站

🔗 **在线访问**：[https://paitaising.github.io/resume](https://paitaising.github.io/resume)

## 📋 项目简介

这是一个专业的个人介绍网站，用于展示张笑源的个人信息、技术能力、项目经历和联系方式。

## ✨ 功能特点

- 🎨 现代简洁的设计风格
- 📱 完善的响应式布局（手机、平板、电脑）
- ✨ 流畅的滚动动画效果
- 🧭 智能导航栏（自动隐藏/显示）
- ⬆️ 返回顶部按钮
- 📊 数字计数动画
- 🎯 卡片3D倾斜效果
- ♿ 无障碍支持

## 🛠️ 技术栈

- HTML5
- CSS3（CSS变量、Flexbox、Grid、动画）
- JavaScript（ES6+、Intersection Observer）
