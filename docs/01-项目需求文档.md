# 项目需求文档

## 项目名称

张笑源 - 个人介绍网站

## 项目目标

制作一个专业的个人介绍网站，用于展示：
- 个人信息和联系方式
- 技术能力和专业技能
- 项目经历和工作成果
- 教育背景和荣誉奖项

## 目标用户

- 潜在雇主/HR
- 技术面试官
- 合作伙伴

## 功能需求

### 核心功能

1. **个人信息展示**
   - 姓名、职位、联系方式
   - 个人简介/优势描述

2. **技能展示**
   - 技术能力分类展示
   - 可视化技能水平（可选）

3. **工作经历**
   - 公司名称、职位、时间
   - 工作内容和成果

4. **项目经历**
   - 项目背景
   - 个人职责
   - 项目成果

5. **教育背景**
   - 学校、专业、时间
   - 主修课程

6. **荣誉奖项**
   - 竞赛获奖
   - 奖学金等

7. **联系方式**
   - 电话、邮箱
   - 可选：微信、LinkedIn等

### 交互功能

1. **导航菜单** - 快速跳转到各板块
2. **平滑滚动** - 点击导航时平滑滚动到对应位置
3. **响应式设计** - 适配手机和电脑
4. **返回顶部** - 长页面快速返回顶部

## 非功能需求

1. **性能** - 页面加载速度快
2. **兼容性** - 支持主流浏览器
3. **可访问性** - 语义化HTML，易于阅读
4. **可维护性** - 代码结构清晰，易于修改

## 技术约束

- 纯静态网站（HTML + CSS + JavaScript）
- 不需要后端服务器
- 可部署到GitHub Pages等免费托管平台

## 设计要求

- 专业、简洁、现代
- 色彩搭配舒适
- 排版清晰易读
- 体现技术能力和审美水平
